# TD-001 Wokyis M5 真机矩阵

## 结论

- 已在真实连接的 `Wokyis` 显示器上确认 macOS 可通过 `NSScreen` 和 Core Graphics
  识别设备；当前逻辑分辨率、物理像素均为 1280×720，缩放系数为 1，刷新率为
  60 Hz，当前处于 online / active 状态。
- 当前一次采样不足以证明直连、扩展坞、休眠恢复和 50 次拔插均能在 5 秒内恢复，
  因此 GATE-01 暂不放行。
- 原型使用固定 1280×720 画布；静态字号检查显示正文基线为 14 px、辅助信息最小
  11 px。尚未在 5 英寸真机正常观看距离完成四页无裁切和“核心数字 3 秒可读”人工
  验收，因此 GATE-05 暂不放行。
- EDID 上报的物理尺寸约为 290×169 mm，与 5 英寸目标设备明显不符；序列号为
  `0x01010101`，也呈现通用占位值特征。`DisplayController` 不得用物理尺寸、
  `CGDirectDisplayID` 或序列号中的任意单一字段识别 M5，应使用名称、vendor、model、
  当前模式和用户选择组成候选指纹，并始终保留手选回退。

## 测量工具

`tools/M5DisplayProbe.swift` 直接读取 AppKit / Core Graphics，不依赖网页、驱动、
Cookie 或私有容器。它提供：

- `snapshot`：记录名称、显示器 ID、逻辑/物理分辨率、缩放、刷新率和候选指纹字段；
- `watch`：每 100 ms 起轮询目标屏，记录拔出、重新出现、系统休眠/唤醒及恢复耗时；
- JSONL 事件只包含目标显示器，避免采集无关显示器标识；
- 已存在的输出文件不会被覆盖。

构建并采样：

```bash
mkdir -p .build/td-001
xcrun swiftc -parse-as-library \
  -swift-version 6 \
  -strict-concurrency=complete \
  -warnings-as-errors \
  tools/M5DisplayProbe.swift \
  -o .build/td-001/M5DisplayProbe

.build/td-001/M5DisplayProbe snapshot --target-name Wokyis
```

记录一组物理测试（停止监测使用 Control-C）：

```bash
.build/td-001/M5DisplayProbe watch \
  --target-name Wokyis \
  --output td001-wokyis-events.jsonl \
  --interval 0.1
```

JSONL 是本地诊断证据，复核无无关标识后再附到 issue；不要提交主机序列号、平台
UUID 或包含其他显示器标识的 `system_profiler` 原始输出。

## GATE-05 人工验收

在 Wokyis 原生 1280×720 模式上逐页显示总览、套餐、Token、设置：

1. 记录浏览器/应用实际占用为 1280×720，整体缩放 1.0；
2. 由测试者在正常观看距离读取核心数字，逐页记录是否在 3 秒内正确读出；
3. 检查正文不低于 14 px、辅助信息不低于 11 px；
4. 检查四边、长 Provider / 模型名、大金额、0% / 100% 状态无裁切或滚动条；
5. 对失败页面保存照片或截图，并记录距离、页面、字段和裁切位置。

只有上述人工验收全部通过，GATE-05 才可改为通过。

## 失败处置与后续约束

- `CGDirectDisplayID` 在拔插后若变化，不能作为持久化主键。
- Vendor / Model / Serial 在不同链路若变化，匹配策略必须降级到组合指纹并提示手选。
- 任一恢复超过 5 秒，TD-020 必须保留主屏安全回退、手选屏和可重试的重定位流程。
- EDID 物理尺寸不可信，设计画布和缩放只依据逻辑 frame、显示模式物理像素及
  `backingScaleFactor`，不依据 DPI 推导。
- 完成矩阵后，在本文件补充逐组合统计（min / p50 / max、失败次数、变化字段）与
  失败明细，再将 GATE-01 / GATE-05 结论改为最终状态。
