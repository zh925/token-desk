# Token Desk 数据生命周期与导出

## 数据口径

套餐窗口、Token、费用和余额分别存储，清理与导出不会在这些口径之间换算。Token
历史按分钟、小时和每日粒度保存；费用记录保持原始币种与十进制定点文本，不跨币种合计。

## 保留与清理

- 分钟记录保留 7 天，过期前先按账户、Provider、项目、工作空间、模型和时区聚合为小时记录。
- 小时记录保留 90 天，过期前按同一组维度聚合为每日记录。
- 每日记录默认保留 730 天，之后删除。
- 自动保留任务在单个数据库事务中先聚合再删除；失败或取消会回滚，避免缺口。
- 手工清理可限定一个 Provider，也可清空全部本地历史。套餐、Token、费用、余额及关联告警事件在同一事务中清理；Provider/账户设置和 Keychain 凭据不受影响。
- 设置页显示 SQLite 当前占用估算及历史行数。WAL 空间会由 SQLite 自行检查点回收，因此界面数值不是导出文件大小。

## 导出

用户可按起止时间（结束时间不包含）、Provider、账户、项目和 Token 粒度筛选。Token 与费用保持为不同的 `dataType` 记录，避免把缺少模型维度的官方费用错误分摊到模型 Token 上。

CSV 使用 UTF-8 BOM 和 RFC 兼容的双引号转义；JSON 使用同一字段白名单。白名单仅包含：时间、数据类型、Provider 展示名、账户别名、模型、粒度、四类 Token、费用、币种、来源类别和估算标记。

导出明确排除：API Key、Keychain 引用、Prompt、响应正文、本地账户/Provider ID、完整远端账户/组织/项目/工作空间标识，以及可能携带远端细节的来源原始标识。项目引用只参与筛选，不进入文件。

导出数据生成和序列化都会传播任务取消。生成完成后仅通过 `NSSavePanel` 获取单个用户选定文件的写权限；取消保存面板不会创建或修改文件。MVP 不申请 Documents 或 Downloads 的广泛访问权限，也不持久化目录书签。

## 验证边界

自动化测试覆盖筛选、中文与 CSV 转义、UTF-8 BOM、大整数 Token、十进制费用精度、字段白名单、取消传播、Provider/全部清理事务和设置保留。Release App Sandbox 的真实保存面板、签名与干净账户验证归入 TD-064 发布回归，不以 Debug 测试替代。
